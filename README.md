# ER-CraftyMerchants-Helper
Helper to setup the Dll Mod designed for compatibility with ANY modpack for Elden ring 1.71.1 I allows you to attach a new kind of "Shop" to any friendly NPC's on your game, a custom/exclusive crafting table separated from the player's own creation menu (you have to use the npc for the crafting) perfect for NPC flavor, or survival like mods.
